一、執行成果摘要

資訊部資本支出規劃聚焦於資訊基礎架構、資訊安全、企業系統、研發工具及 AI 應用。依提供之專案清單，共計 22 項，已執行 11 項、未執行 11 項。未執行項目涵蓋時程調整、技術驗證、需求變更及外部計畫取消等原因。

二、勞務費用概況

除年度資本支出外，資訊部另有勞務費用總額 13,495,000 元（1,349.5 萬元），主要涵蓋系統維護合約、訂閱費及 程式外包等項目，以支援既有資訊系統的持續運作與外部技術服務需求。依年度規劃，勞務費用將於 2026 年底前全數執行，預計執行率為 100%。

五、未執行專案分析

未執行預算合計 1,740 萬元。依原始原因說明，歸納如下：

原因類別涉及專案金額
時程及優先順序調整台中廠交換器汰換、服務維修 App610 萬
政府科專計畫取消NDR＋XDR、資安自動化工具350 萬
廠商及技術成熟度不足上網行為管理、File Server Log、AgentFlow、Lale App425 萬
既有方案替代SPAM 防護（改採 Exchange Online）130 萬
AI POC 未達預期AI 智能系統75 萬
需求變更取消AD 整合升級150 萬
合計11 項1,740 萬

重點原因說明

  • 時程調整：台中廠網路設備列為空調優化後的第二階段；服務維修 App 因 SCM 專案而暫緩，列入 2027 年度工作項目。
  • 適用性評估：上網行為管理與 File Server Log 尚未找到完全符合需求的廠商，預計持續尋找合作方案。
  • 外部計畫異動：NDR＋XDR 與資安自動化工具因原配合的政府科專計畫取消而停止。
  • 技術驗證：AgentFlow 新版穩定度不足、Lale App 測試異常；AI 智能系統 POC 使用者回饋未達預期。
  • 避免不必要投資：SPAM 改採 Exchange Online 既有功能；AD 升級因核心需求變更而取消。

六、執行成效與管理價值

年度資本支出管理不僅著重執行率，也應兼顧投資必要性、技術成熟度及營運風險。

已執行項目涵蓋 SAP 備援、資料備份、vSAN、資安及研發工具，對資訊基礎能力具有重要意義。未執行項目則反映部分專案經過評估後採取延後、替代或取消決策；但對延後的資安監控與設備汰換仍應持續追蹤風險。

八、結論

資訊部本年度規劃資本支出 3,921.2 萬元，實際執行 2,181.2 萬元，執行率約 56%。整體以「核心優先、風險控管、效益導向」為原則，完成重要基礎架構、資料保護及資訊安全投資，並依專案適用性與需求變化調整未執行項目。另有勞務費用 1,349.5 萬元，涵蓋系統維護合約、訂閱費及程式外包，預計於 2026 年底全數執行，年底預計執行率 100%；後續宜持續追蹤延期專案的風險、替代方案成效及 2027 年工作規劃，並建立勞務費用分項與執行追蹤機制。
